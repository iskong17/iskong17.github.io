Overview of the proposed SATOR framework. SATOR introduces a source-free and backpropagation-free 3D TTA architecture that computes token abnormality scores from complementary attention and geometric relation graphs, adaptively derives sample-specific token partitions via Otsu-based separability, and routes predictions using keep-ratio-calibrated routing without evaluating candidate purge sizes.

Abstract

Test-time adaptation (TTA) mitigates the performance degradation of source-pretrained models on unlabeled test data under distribution shifts. Recent backpropagation-free token-purging methods address 3D point cloud distribution shifts by filtering unreliable tokens. However, their reliance on predefined purge-size candidates requires multiple forward passes per sample and increases inference cost.

We propose SATOR (Sample-Adaptive TOken Routing), a source-free and backpropagation-free 3D TTA framework that eliminates this search by deriving both the partitioning threshold and routing decision directly from each sample. SATOR computes token abnormality scores from complementary attention and geometric relation graphs. It then derives a sample-specific partition into retained and pruned tokens via Otsu-based separability, without evaluating candidate sizes. Keep-ratio-calibrated routing then selects the pruned prediction only when its entropy, penalized by the keep ratio, is lower than that of the original prediction. Extensive experiments on ModelNet40-C, ScanObjectNN-C, and ShapeNet-C demonstrate that SATOR achieves state-of-the-art accuracy on three 3D corruption benchmarks.

Backpropagation-Free 3D Adaptation

Conventional 3D TTA approaches rely on gradient-based backpropagation during inference, incurring excessive computational cost and memory footprints. SATOR operates completely without backward passes or source data, making it highly suitable for resource-constrained edge systems.

Complementary Attention & Geometric Relation Graphs

Instead of relying on stored global statistics or self-attention alone, SATOR synergizes internal self-attention maps with spatial geometric relation graphs ($K_g$-NN affinity) to quantify how corruptions disrupt local neighborhood structures and reliably score abnormal tokens.

Otsu-Based Search-Free Token Partitioning

Prior token-purging methods evaluate multiple predefined purge-size candidates through iterative forward passes. SATOR completely eliminates candidate search by deriving an optimal sample-specific threshold directly from the score distribution via Otsu-based separability.

Keep-Ratio-Calibrated Dual-Branch Routing

SATOR compares predictions from the original sequence and the pruned sequence. To prevent low entropy from being favored solely due to aggressive token reduction, it calibrates prediction entropy by the keep ratio ($\rho = |\mathcal{K}|/M$), selecting the pruned branch only when $\frac{H(z_{\mathrm{prune}})}{\rho} < H(z_{\mathrm{orig}})$.
